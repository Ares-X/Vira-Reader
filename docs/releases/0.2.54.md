# Vira Reader 0.2.54

- CBZ pages reuse the archive read that retrieved their image headers. This reduces repeated ZIP scans when reading or jumping to later pages. [#175](https://github.com/Ares-X/Vira-Reader/issues/175)
- Comic page order stays consistent when two filenames compare equally in natural sorting, including differences in case or leading zeros. [#176](https://github.com/Ares-X/Vira-Reader/issues/176)
- Switching HTML or CHM topics no longer reports a canceled earlier navigation as the current page's error. [#177](https://github.com/Ares-X/Vira-Reader/issues/177)
- Applying redactions also removes affected replacement text from tagged PDFs. [MuPDF fix](https://github.com/ArtifexSoftware/mupdf/commit/ab37474fcb41d23acdbc0c6be3cf8c97d32dceff)

Update with **Help → Check for Updates**. Apple Silicon · macOS 13 or later.
